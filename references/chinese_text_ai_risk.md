# 中文学术论文 AIGC 检测特征与低风险改写规范 (Chinese Academic AI Risk Reference)

**规范版本**: 2.21.0  
**适用范围**: 中文硕士/博士学位论文、学术期刊投稿、知网 (CNKI) AIGC 检测应对  
**机构归属**: KalarisLabs Modular Academic Skill

---

## 1. 语言路由与知网 (CNKI) 双区检测架构

中文学位论文的 AIGC 风险特征与英文存在显著的句法和语用差异。执行中文论文诊断时：
1. **独立中文路由**：严禁机械套用英文 D1–D17 词汇量表；必须采用**中文十项证据字段**并报告 `chinese_paragraph_risk_estimate`。
2. **严禁混淆规则**：中文母语论文不得适用“中国学生英语陈词滥调库”（该规则仅适用于中国作者撰写的英文论文）。
3. **知网 (CNKI) 双区高危扫描策略**：
   - **前置区 (Front-Loaded Zone)**：摘要、绪论、研究背景、文献综述。AI 生成往往呈现宏大叙事、缺乏具体行业与痛点张力的平滑套话。
   - **后置区 (Back-Loaded Template Zone)**：研究结论、管理启示、对策建议、研究局限与展望（尤其是 MBA / 管理学专硕论文）。该区域极易出现排比句、宏观政策口号式对策及缺乏数据锚定的空泛建议。

## 2. 中文路由固定十项证据字段 (Fixed Ten Evidence Fields)

对评估和选定改写的每一个中文段落，必须完整记录以下十项证据，严禁输出残缺表格：

```text
================================================================================
中文段落 AIGC 诊断与改写证据表
================================================================================
[1] 中文模板短语命中: [列出命中的套话开头、收束词或过渡短语，无则填“无”]
[2] 中文高频连接/收束模式: [列出堆叠的连接词或空泛总结模式]
[3] 无依据夸张词或空泛价值判断: [列出未锚定实证数据的拔高用语]
[4] 术语/数据/引用保护项: [列出必须逐字锁定的变量名、统计值(β, t, p, R²)、问卷样本量及文献引用]
[5] 段落架构风险: [低 / 中 / 高 - 诊断段落内部展开是否呈机械模板]
[6] 跨段重复结构风险: [低 / 中 / 高 - 诊断相邻段落是否呈现并列骨架复制]
[7] 方法/结果报告序列风险: [低 / 中 / 高 - 诊断测量与假设检验汇报序列是否机械循环]
[8] 外部检测高亮证据: [记录知网AIGC连续标红字符片段或特征值]
[9] chinese_paragraph_risk_estimate: [内部综合风险估值: 0% - 100%]
[10] 对应改写动作与同段字数补偿记录: [记录执行的具体改写技术(如T1, T14, T18)及字数前后对比(改写后必须 >= 原字数)]
================================================================================
```

## 3. 中文高危 AI 表达与句式特征库 (High-Risk Phrase Catalog)

### 3.1 模板化开头 (Template Openings)
- **高危词组**：
  - “随着……的飞速发展 / 快速推进 / 广泛应用 / 日益普及……”
  - “在当前……的大背景下 / 在……日益凸显的今天……”
  - “近年来，……引起了学术界和实务界的广泛关注 / 高度重视……”
  - “基于以上背景，本文试图探讨……”
- **去模板策略**：直接切入具体的现实业务痛点、行业制度矛盾或实证矛盾点，删除宏大背景铺垫。

### 3.2 机械收束与空泛价值判断 (Template Closings & Empty Claims)
- **高危词组**：
  - “综上所述 / 总而言之 / 不难发现 / 显而易见……”
  - “具有重要的理论意义和实践价值 / 现实启示……”
  - “为……提供了有益的借鉴和参考 / 坚实的理论支撑……”
  - “本文的可能创新之处主要体现在以下几个方面……”
- **去模板策略**：用具体的研究发现（如“本研究明确了心理安全感在算法监控下的非线性衰减界限”）替代泛化评价。

### 3.3 无依据夸张与空泛成效用语 (Unsupported Intensifiers)
- **高危词组**：
  - “毫无疑问”、“不可否认”、“深刻地揭示了”、“极大提升了”、“具有不可替代的关键作用”。
- **统计术语严格保护豁免 (Discipline Protection Carveout)**：
  - **重要原则**：当“有效”、“明显”、“提升”等词直接用于描述经过统计检验的回归系数、路径显著性或实验组对照结果时（例如“结果表明，人机协同对员工创新行为具有显著的正向促进作用，假设H1得到验证”），**严禁将其判定为 AI 套话并严禁擅自修改**！保护学术严谨性高于文字润色。

### 3.4 系词回避 (Copula Avoidance)
- **AI 特征**：刻意避免使用平实的“是”或直接述谓，过度包装为臃肿的关系短语。
  - “作为……的重要代表” $\rightarrow$ 改为直述 “是……”
  - “扮演着不可或缺的重要角色” $\rightarrow$ 改为具体的行为机制说明
  - “充分体现了……的核心本质” $\rightarrow$ 改为具体说明体现了什么特征

### 3.5 浅层因果链堆叠 (Superficial Causal Chain Stacking)
- **AI 特征**：单句中连续串联两个以上推导连词，伪造深度论证气势。
  - *典型高危句*：“……从而提升了员工认同感，进而增强了组织归属感，由此推动了企业整体绩效的跃升。”
  - *改写策略*：切断链条，分句阐述，补充各环节之间的具体中介路径或边界条件。

### 3.6 高频 AI 行业黑话库 (High-Frequency AI Vocabulary)
在缺乏具体操作性定义时，密集出现以下词汇属于典型 AI 痕迹：
`赋能, 助力, 维度, 范式, 纵深推进, 协同增效, 深度契合, 逻辑闭环, 擘画, 矩阵, 载体, 抓手, 催化, 锚定`。

### 3.7 随意变体与术语不一致 (Anti-Elegant Variation)
- **学术规范**：同一概念必须通篇保持绝对统一的中文术语。严禁为了“避免文字重复”而在相邻段落随意轮换代称（如在一处称“被调查者”，下一处称“受访员工”，再下一处称“问卷填写人员”；或同一个自变量名称在不同章节出现微调）。保持术语一致性是学术论文的核心指标。

## 4. 知网 (CNKI) 特征值防聚集与安全断句规范

1. **防聚集与断点注入 (Gate E 适配)**：
   - 知网检测算法对连续相似字数（通常为 13 字以上重合或高密度特征值聚集）极其敏感。
   - 严禁合并段落！合并段落会造成特征值大面积聚合连片。
   - 若段落过长（超过 300 字），应在逻辑转折处拆分为独立段落；可插入基于论文真实数据的锚点句（如具体的样本均值、问卷信效度指标或行业实测指标），破坏连续特征值。
2. **字数底线与中文同段补偿 (Gate F 适配)**：
   - 中文学位论文具有极其严苛的最低字数审查要求。
   - 删除套话连词（如“随着……”）后，**必须在同段内补充具体的定语、变量操作化说明或实证情境细节**，确保改写后段落字数 $\ge$ 原段落字数（增长区间控制在 $0\% \sim +15\%$）。
3. **中文标点与断句完整性 (Gate H / I 适配)**：
   - 严禁制造单句无主语、无谓语的悬空短语（如将“包括多变量回归分析与因子分析。”作为独立句子输出）。
   - 严格消除英文字符乱码 (Mojibake)、中文全角/半角标点混用。
   - 正文中严禁使用流程图箭头“$\rightarrow$”（仅限表格内部使用）。
