# Triage Label Vocabulary

Canonical 5-role triage labels configured for `academic-unslop-skill`:

- `needs-triage`: Freshly submitted issue requiring categorization and priority evaluation.
- `needs-info`: Requires additional input, detector reports, or context from the user.
- `ready-for-agent`: High-confidence, scoped task ready for autonomous agent execution.
- `ready-for-human`: Architectural, policy, or academic-integrity decision requiring human review.
- `wontfix`: Out-of-scope, detector-bypass request, or invalid submission.
